Act I

The Memory Wall & The Re-Association Trick

Standard Transformers retain context by caching every past token's key and value vectors. As sequence length \(T\) grows, so does the cache — linearly. But what if we could accumulate the same information into a fixed-size state?

KV-Cache Memory vs Synaptic State Memory 🔵 Live Empirical

KV-cache memory grows proportionally with sequence length \(T\). Synaptic state memory remains constant regardless of how many tokens are processed.

The Re-Association Trick 🟢 Established · Katharopoulos et al., 2020
\(\displaystyle y_t = \sum_{\tau=1}^{t}\) ( \(q_t \, k_\tau^\top\) ) \(v_\tau\) \(\displaystyle y_t = q_t\) ( \(\displaystyle\sum_{\tau=1}^{t} k_\tau^\top v_\tau\) ) \(= q_t \, \mathbf{S}_t\)

Act II

When Attention Becomes Synapses

The accumulator \(\mathbf{S}_t\) updates by adding an outer product at each step. This shares mathematical form with a rule proposed by Donald Hebb in 1949: "Neurons that fire together, wire together."

The Hebbian Correspondence 🟢 Established · Hebb 1949, Schmidhuber 1992, Kosowski et al. 2025

\(\mathbf{S}_{t+1} = \mathbf{S}_t + k_t^\top v_t \implies \Delta S_{ij} = k_{t,i} \cdot v_{t,j}\)

The outer-product update accumulating key-value pairs shares mathematical form with Hebbian synaptic plasticity: \(\Delta W_{ij} \propto \text{pre}_i \times \text{post}_j\)

    Sparse representations can reduce expected overlap between stored associations, making associative crosstalk less likely. But sparsity is not magic: too little activity can reduce representational capacity.

    The Frontier: BDH & BDH-CQ

    The Frontier

    The Uncomfortable Trade-Off

    Fixed State → Constant Memory w.r.t. T → Bounded Capacity → Compression → Interference

    Growing KV-Cache → Perfect Recall → O(T · d) Memory → Bandwidth Bottleneck
    🔴 Honest Limitations:
    • As sequence length \(T \gg N\), even sparse Hebbian memory saturates (capacity bound).
    • Linear recurrence without decay treats past tokens additively; precise order requires positional modulations like RoPE.
    • GPUs excel at dense matrix math; achieving real hardware speedups with sparse Hebbian updates may require specialized sparse kernels or neuromorphic substrates.
    • BDH-CQ results are developer-reported with independent score audit, but cost figures and architectural details are proprietary.
