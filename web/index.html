The Two Paths of Memory

Consider an enterprise conversation that spans 50 turns. A crucial detail is discussed at the very start, and queried at the end:

Turn 3 · Client Proposal
"Section 14.2: The maximum indemnity cap is set to $1,450,000 with net 30 payment terms."
46 turns of intervening discussion
Turn 50 · Query
"What was the exact financial indemnity cap we agreed on earlier?"

How should the model respond?

Strategy A

Verbatim Store

"In Section 14.2, the maximum indemnity cap is set to $1,450,000 with net 30 payment terms."

Recall Style: 100% Literal / Exact
Memory Footprint: Keeps every past word
Strategy B

Compressed State

"The agreement specifies an indemnity limit of approximately $1.45M with standard 30-day payment settlement terms."

Recall Style: Semantic Gist / Meaning
Memory Footprint: Fixed-size internal state

Teaching simplification — not a live computation.
