Chapter 2

Naive Recompute vs. The Cache

During autoregressive generation, predicting each new token requires attending over all previous tokens in the sequence. Without caching, the model repeatedly recomputes the Key and Value projections for every historical token at every single generation step. KV caching stores these projections after their first computation, eliminating repeated projection work while attention continues to operate over the growing context.

No Cache: cumulative K/V projection work grows quadratically with sequence length (O(N²D²)) because previous projections are repeatedly recomputed. With KV Cache: cumulative K/V projection work grows linearly (O(ND²)) because each K/V projection is computed once, while attention interaction work continues to grow with context length (O(N²D)).

● Established · Vaswani et al. 2017 (Attention formulation)

Vaswani et al. (2017) introduced the multi-head attention formulation: Attention(Q, K, V) = softmax(QKᵀ / √d)V. KV-caching emerged as a standard inference optimization in subsequent autoregressive sequence serving systems.
